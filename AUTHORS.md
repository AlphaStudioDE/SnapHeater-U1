# Authors

## Original author and project origin

**SnapHeater U1** was originally created and published by:

**Damian Borkowski**  
GitHub handle: `@damianborkowski88`

This repository is the original upstream project for SnapHeater U1, a Snapmaker U1-focused chamber-heater firmware framework for Panda Breath-style ESP32-C3 hardware.

## Project revival acknowledgement

The revival of SnapHeater U1 as firmware for the original Panda Breath
V1.0/V1.0.1 electronics was made possible by the work of
[`plastikman`, author and maintainer of DragonBreath](https://github.com/plastikman/DragonBreath).

Their reverse-engineering, hardware investigation, validation and public
documentation supplied the essential Panda Breath hardware map, held-gate
fan/TRIAC behavior, zero-cross findings, NTC conversion and thermal-safety
knowledge used as the foundation of the revived project.

This acknowledgement records the contribution that enabled the revival; it
does not imply that `plastikman` is responsible for SnapHeater U1-specific code,
features, modifications or releases.
